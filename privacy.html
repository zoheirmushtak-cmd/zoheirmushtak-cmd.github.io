Privacy Policy

Unconventional Wisdom Uploader. Effective November 8, 2026.

Unconventional Wisdom Uploader is a private tool that the owner of the Unconventional Wisdom YouTube channel uses to manage that channel's own videos. It is not offered to the public.

What the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API to upload videos to the owner's channel, read the channel's video list and schedule, and set video titles, descriptions, tags, captions and thumbnails.

How the data is stored

The sign-in token that Google issues is stored only on the channel owner's own computer. The tool has no server and no database, and it does not collect information about YouTube viewers.

Sharing

The tool sends channel data only to YouTube, in order to carry out the actions above. It does not sell, share or transfer Google user data to anyone else, and it does not use that data for advertising.

Limited Use

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be withdrawn at any time from the Google Account permissions page. Deleting the token from the computer also ends the tool's access from that computer.

Changes and contact

Any changes to this policy will be posted on this page. Questions can be sent to zoheirmushtak@gmail.com.
